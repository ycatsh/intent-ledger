Payee is who the money went to. Category is the destination account. Usually a spending category, but it can also be an existing balance sheet account (Checking, a loan, etc.) if you type its exact name. Most payees carry a default category.

Assignments

  • New payee, new category: sets that payee's default.
  • Payee, different category than its default: saves a one-off override for that transaction. The payee's default stays the same.
  • No payee: saves a rule matching that description. No override, the rule alone decides it going forward. Flagged for review.
  • Category name doesn't match an existing account: creates it as an expense category, flagged for review.

Grouping

  • Transactions group by description, biggest groups first. Assign a group once, every matching transaction gets categorized with it.
  • Intelligent grouping folds together descriptions that look like the same payee written slightly differently. Expand a group to check the transactions before assigning it.
  • No grouping turns grouping off. Every transaction gets its own row, even exact duplicates.
